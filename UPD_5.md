## 5. Зарезервировать место под ошибки у каждого поля

Перестроить отображение validation errors так, чтобы каждая ошибка находилась непосредственно под тем control/block, к которому относится.

Требования:
- ошибка `Название` — сразу под `Название`;
- ошибка `Где` — сразу под `Где`;
- ошибки дат — под соответствующим date-блоком/строкой дат;
- ошибка `Формат плана` — под блоком формата;
- ошибка `Бюджет` — под бюджетом;
- ширина error-container должна совпадать с шириной соответствующего control;
- текст ошибки переносить внутри этой ширины;
- ошибка не должна уезжать под соседнюю колонку;
- для двухколоночных рядов каждый control должен иметь собственную вертикальную структуру: `label -> input -> error`;
- предусмотреть стабильное место под error text, чтобы появление ошибки не ломало соседний layout и не сдвигало unrelated блоки хаотично;
- не выводить общую ошибку формы вместо field-level error, если ошибка относится к конкретному полю.

Commit:

`ui-29-field-error-layout`

## 11. Сделать PDF форматом экспорта по умолчанию и отправлять экспорт в ЛС бота

В блоке `Экспорт группы`:

- значением по умолчанию установить `PDF`;
- после открытия страницы selector сразу показывает PDF;
- CSV/XLSX оставить доступными как альтернативы.

Изменить действие основной кнопки:

вместо сценария, ориентированного только на скачивание файла, основной сценарий внутри MAX должен быть:

`Подготовить экспорт -> отправить готовый файл пользователю в личный чат с ботом`.

Требования:
- использовать существующую персональную MAX-привязку пользователя;
- НЕ использовать групповые MAX-чаты;
- отправлять файл именно пользователю, который запросил экспорт;
- сохранить выбранный формат;
- для PDF использовать корректный filename и MIME type;
- если пользователь не подключил личные уведомления/бота и отправка невозможна — показать короткую понятную ошибку рядом с блоком экспорта;
- не считать export успешным, пока backend не подтвердил отправку файла;
- не ломать существующую генерацию CSV/PDF/XLSX;
- если текущая backend-модель уже создаёт export-файл, переиспользовать её, не генерировать второй файл отдельно.

UI-кнопку можно назвать:

`Отправить файл в MAX`

или сохранить текущий текст, если он уже корректно отражает действие.

Commit:

`ui-35-export-pdf-to-bot`
